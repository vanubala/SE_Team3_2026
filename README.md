# 📦 Smart Parcel Locker System
> Software Engineering 1 -- Team 3

## Overview
The **Smart Parcel Locker System** is a software and hardware management platform designed to streamline last-mile parcel delivery and collection through shared automated locker stations. It eliminates failed home deliveries, optimizes compartment utilization, and enables contact-free package retrieval.


The system serves three user roles :
* **Couriers:** Log into the web dashboard to register inbound parcels, receive automated smallest-fit compartment recommendations, and reserve boxes; deposit packages at physical locker terminals by scanning/entering the **Parcel ID**.
* **Recipients (Guest-First MVP):** Receive an automated SMS/Email notification upon deposit containing a single-use **PIN / QR code**, station location, opening hours, and a **7-day pickup deadline** to unlock their compartment without requiring an account.
* **Administrators:** Monitor real-time locker occupancy across sites, inspect operational health/faults, and toggle station or compartment availability (`AVAILABLE`, `OCCUPIED`, `MAINTENANCE`).
