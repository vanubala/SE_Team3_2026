# Smart Parcel Locker Management System

**Confirmed topic:** 

A platform for managing parcel delivery and collection through shared lockers. 

- Couriers register incoming parcels and assign suitable lockers
- Recipients receive pickup information
- Administrators monitor locker availability and operational status
